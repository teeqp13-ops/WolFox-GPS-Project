# WolFox Activation System

## 1) السيرفر (backend/)
- ارفع مجلد `backend/` كامل على السب دومين الجديد (مثال: activate.p3nd.fun).
- أول طلب على أي صفحة بينشئ قاعدة SQLite تلقائياً (database.sqlite) — تأكد المجلد قابل للكتابة (755/775).
- **مهم:** اضبط `WOLFOX_ADMIN_PASSWORD` كمتغير بيئة على الخادم. لا تضع مفاتيح أو كلمات مرور داخل PHP أو تطبيق iOS.
- لوحة التحكم: استخدم الرابط الفعلي لخادمك. لا توجد كلمة مرور افتراضية؛ يلزم ضبط `WOLFOX_ADMIN_PASSWORD`.
- نقطة التفعيل (API): `https://activate.p3nd.fun/api.php`

## 2) تطبيق iOS (ios/)
- أضف `WFActivationViewController.h` و `.m` للمشروع.
- في AppDelegate/SceneDelegate:

```objc
if ([WFActivationViewController isDeviceActivated]) {
    // روح مباشرة للشاشة الرئيسية
} else {
    WFActivationViewController *vc = [[WFActivationViewController alloc] init];
    vc.delegate = self; // اختياري
    // اعرضها كـ rootViewController أو present
}
```

- عدّل بأعلى ملف `.m`:
  - `kWFApiURL` → رابط الـ API الفعلي عندك.
  - لا تضع مفاتيح HMAC داخل تطبيق iOS.

## آلية العمل
1. المستخدم يكتب الكود (8 خانات) ويضغط تفعيل.
2. التطبيق يرسل الكود ومعرّف الجهاز عبر HTTPS إلى واجهة التفعيل.
3. السيرفر يتحقق من التوقيع، ويربط الكود بالجهاز أول مرة، أو يتحقق من التطابق في المرات اللاحقة.
4. يعتمد الاتصال على HTTPS؛ لا يحتوي العميل على سر مشترك قابل للاستخراج.
5. عند النجاح، التطبيق يحفظ حالة التفعيل محلياً في NSUserDefaults.

## لوحة التحكم
- توليد أكواد (دفعات حتى 100 كود بالمرة) مع تحديد مدة صلاحية اختيارية بالأيام (0 = بدون انتهاء).
- عرض/فلترة حسب الحالة (غير مستخدم / مفعّل / موقوف / منتهي).
- زر "عرض المعلومات" (أيقونة ⓘ) على كل كود يفتح نافذة فيها: الكود، معلومات الجهاز (الموديل + الإصدار)، UUID، تاريخ الاستخدام، تاريخ الانتهاء.
- فك ربط الجهاز عن كود معيّن (يرجعه غير مستخدم).
- إيقاف كود أو حذفه نهائياً.
- الأكواد المنتهية تتحول تلقائياً لحالة "منتهي" عند فتح اللوحة أو عند أي محاولة تفعيل.
